电容器与定义式

两个彼此绝缘、相距很近的导体，能够储存电荷与电场能。
C = QU
C 电容（F）· Q 电荷量（C）· U 电压（V）
1 F = 1 C/V；C 不由 Q、U 决定。

平行板决定式

电容由几何结构与介质决定。
C = εrS4πkd
εr 相对介电常数 · S 正对面积
d 板间距 · k 静电力常量
核心：C ∝ εrS / d

板间场强

平行板间为匀强电场，方向由 + 指向 −。
E = Ud = 4πkQεrS
断电源时 Q 不变：
E 与板间距 d 无关，只由面密度与介质决定。

电场能量

充电把其他能转化为电场能储存在板间。
W = 12CU² = Q²2C = 12QU
接电源用 ½CU²，断电源用 Q²/2C 最方便。

F = qE，a = qE/m　｜　x = v₀t，y = ½at² = (qE / 2mv₀²)x²
水平匀速、竖直匀加速 → 板间轨迹为抛物线；飞出后沿切线匀速直线。偏转量随 q、E 增大而增大，随 m、v₀ 增大而减小。
T = 2π√LC　｜　f = 1 / (2π√LC)
q 最大时 i=0（电场能最大）；i 最大时 q=0（磁场能最大）。电场能与磁场能每 T/2 转化一次，理想无阻尼时总能量守恒。极板电荷符号随相位增减并翻转。
串联 1/C = Σ1/Cᵢ（等电荷 Q）　｜　并联 C = ΣCᵢ（等电压 U）

串联电荷量相等，电压按电容反比分配；等效电容比任一个都小（相当于增大 d）。

并联电压相等，电荷量按电容正比分配；等效电容为各电容之和（相当于增大 S）。

被测量 → 改变 d / S / εr → 改变 C → 转换为电信号

压力：膜片下弯 → d↓ → C↑

位移：极板错开 → S↓ → C↓

液位：液面↑ → 等效 εr↑ → C↑

共同本质：C ∝ εrS/d。测出电容 C 的变化，即可反推压力、位移、液位等被测量。
